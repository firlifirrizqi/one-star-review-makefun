# One-Star Review of Something Essential

One funny deadpan one-star review of an everyday essential, written for the [Make.fun bounty](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629).

`main.py` writes the line to `/output/entry.txt`:

> One star. Paid eight hours, woke up tired, and the dreams were just my job with worse lighting.

Run it with `python3 main.py`.
